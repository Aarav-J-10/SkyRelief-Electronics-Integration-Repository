# Source provenance and rights

**Historical SkyRelief hardware dossier with modern engineering reconstruction.** Source-supported components and connectivity are distinguished from new reference implementations. Unrecovered pin assignments, firmware parameters and code must not be treated as as-built records or electrically validated flight instructions.

The authored full-resolution sketch has source/release hashes in the asset manifest. It is historical raster evidence, not a recovered EDA source. New schematics and vector diagrams are explicitly source-derived or new reference work.

DroneTrest and JHEMCU graphics, catalogue images and the HAWK'S WORK motor graphic are excluded. Manufacturer guidance supports capability statements, not installed pin allocation; copyrighted full artwork is not copied. See [licensing](../LICENSES.md), [image audit](../data/source_image_audit.csv) and [source register](Source_Document_Register.md). Author-owned material is licensed in release 1.0.0 (see [licences](../LICENSES.md)); excluded third-party material is not.
