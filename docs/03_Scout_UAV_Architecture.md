# Scout architecture

**Historical SkyRelief hardware dossier with modern engineering reconstruction.** Source-supported components and connectivity are distinguished from new reference implementations. Unrecovered pin assignments, firmware parameters and code must not be treated as as-built records or electrically validated flight instructions.

The documented family is GHF411 PRO-BMI 40 A F4 2-6S AIO, four FT Gremlin 1104/5400 KV motors, R81 receiver and Zorro 4-in-1 radio. HQ 2.5x3 and 2.5x2.5x3 both appear; final fitted props are unresolved.

Photo sc9 supports the small guarded quadrotor, not a unique complete PCB revision. The generic JHEMCU source diagram is not an authored installed harness and is excluded. All nine native logical ports remain open with PIN_UNVERIFIED and retained ERC errors. No battery cell count, resource mapping, receiver protocol or GPS-rescue configuration is invented.
