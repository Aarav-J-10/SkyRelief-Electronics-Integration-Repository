# Scout AIO and receiver

**Historical SkyRelief hardware dossier with modern engineering reconstruction.** Source-supported components and connectivity are distinguished from new reference implementations. Unrecovered pin assignments, firmware parameters and code must not be treated as as-built records or electrically validated flight instructions.

Exact PCB revision, MCU/IMU target and motor resource map are unrecovered. BMI-family wording must not be replaced with the different-IMU A04 quote. The 2-6S family label does not establish installed battery voltage.

R81 generation, RF mode, output protocol and AIO input are unresolved. Zorro 4-in-1 is a family label, not a saved radio profile. Similar JHEMCU artwork is not a basis for assigning pads. Native ports remain unconnected to expose these missing specifics. Nine pin_not_connected findings are expected and retained, not suppressed.
