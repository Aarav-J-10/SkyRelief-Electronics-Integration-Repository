# Delivery architecture

**Historical SkyRelief hardware dossier with modern engineering reconstruction.** Source-supported components and connectivity are distinguished from new reference implementations. Unrecovered pin assignments, firmware parameters and code must not be treated as as-built records or electrically validated flight instructions.

The inventory records Pixhawk 2.4.8 family, NEO-M8N GPS/compass, FS-iA6B receiver/FS-i6 ground transmitter, 3DR-family 433 MHz telemetry, safety switch and buzzer. Four 2212/920 KV-family motors, four 30 A-labelled ESCs and 1045 propellers form the propulsion inventory. Exact revisions, motor order and installed firmware remain unknown.

The native historical sheet draws only defensible battery/PDB/ESC/three-phase motor grouping, C01-C03. Controller outputs, RC/GPS/telemetry, power module, safety/buzzer, release and ranging remain annotations or unassigned boundaries. No actual MAIN OUT, FMU, UART or I2C pins are selected. Module high-current insertion/calibration is unresolved. Net names H_M1-A etc denote drawing groups, never physical aircraft motor positions.
